# 난점과 학습 로드맵

목표의 방향성을 결정하는 중요한 축이다. 두 난점은 서로 다른 계층의 문제지만 하나의 인프라를 공유한다.

## 1. 난점 1 — 실시간 라이브 피드백

### 문제 정의

- 사람이 그림 그리듯 모델도 자기 행동 결과를 실시간으로 파악하면서 그려야 한다. 이것은 쉬운 일이 아니다.
- 문자적 실시간(연속 비디오)이 아니라 **논리적 실시간**을 목표로 한다: 판단 시점마다 1~2초 내에 자기 상태를 본다.
- 근거: 인간 화가도 시선(느린 의식적 관찰)과 손(빠른 무의식적 운동)을 시간 분리한다. 현재 LLM 지연시간(왕복 수 초)은 이 케이던스와 양립 가능하다.

### 대응

1. 이중 속도 루프 — 느린 인지 루프(LLM)와 빠른 실행 루프(실행기) 분리. 상세는 `08_agent_redesign_ko.md` 4절.
2. 델타 관찰 — dirty region만 고해상도 크롭, 전체 렌더는 체크포인트에서만, 숫자 신호는 상시.
3. 결정론 사전검증 — VLM 호출 전 무료 체크(의도 bbox 안 찍힘 여부, 픽셀 변화 여부). 실패 시 모델 호출 없이 즉시 재시도.
4. 관찰 압축 — 오래된 이력은 텍스트 요약, 최근 상태만 이미지. 컨텍스트 폭발 방지.
5. 측정기구 피드백 — VLM의 공간 인지 한계(비율·원근)를 각도·비율·엣지의 프로그램적 측정값으로 보완. 화가의 수직선·뷰파인더에 해당.

## 2. 난점 2 — 프로세스 감독 문제

### 문제 정의

- 도구 사용 파인튜닝에는 행동 궤적이 필요하다.
- 그러나 세상에는 완성작 이미지만 있고 그것을 만든 붓질 로그(행동 시퀀스)는 없다.
- 사용자 구상: AI에게 이미지를 주면 그 이미지를 보고 분석하며 따라그리는 방식으로 학습한다. 방향은 맞으며, 핵심 난관은 "따라그릴 때의 궤적을 어디서 얻는가"다.

### 해법 스택

1. 교사 부트스트래핑 (거절 샘플링): 파인튜닝 전 VLM+툴 에이전트가 참조 이미지를 따라그리게 하고, 최종 결과가 참조와 유사한 궤적만 걸러 SFT 데이터로 채택한다 (STaR류 부트스트래핑).
2. 약한 감독 마이닝:
   - 작가 타임랩스 영상(스피드페인트) -> 스트로크 순서·단계 전환의 인간적 사전지식
   - 레이어 분해된 PSD -> sketch->lineart->flat->shade 같은 구조 순서 학습 (정확한 붓질보다 쉽고 가치가 크다)
3. 역렌더링: 참조 이미지 영역을 재현하는 스트로크 파라미터를 탐욕적으로 풀어낸다 (후보 스트로크를 그려보고 개선되면 채택). 인간 시연 없이 궤적을 합성하는 길.

## 3. 학습 로드맵

| 단계 | 방법 | 목적 |
|---|---|---|
| Stage 0 | 프롬프트 엔지니어링 에이전트 (학습 없음) | 베이스라인 + 데이터 수집기 |
| Stage 1 | SFT (필터링된 자가 궤적) | 형식 안정화·기본 역량 |
| Stage 2 | 선호 최적화 (DPO류) | 품질 끌어올리기 |
| Stage 3 | 시뮬레이터 RL | 한계 밀기 |

## 4. 시뮬레이터

- 결정론 실행기는 GUI 없이 numpy 근사로 op를 재현하는 헤드리스 시뮬레이터가 된다.
- 학습 에피소드 처리량이 초당 수백 개 수준까지 올라간다.
- 배포 환경과 같은 검증기를 공유하면 sim-to-real 갭이 거의 없다.
- v0의 "순수 Python 코어 분리" 원칙이 학습 인프라로 회수된다.

## 5. 보상 설계 주의사항

- 픽셀 유사도만 주면 '베끼기'만 학습한다.
- 다항 보상을 쓴다: 최종 일치 + 중간 단계 구조 + 도구 적법성 + 효율 패널티.
- 튜닝 대상은 프론티어 모델 전체가 아니라 미드사이즈 오픈 VLM + LoRA다. 프론티어 모델은 교사·심판으로 유지한다.

## 6. 공유 인프라

- 세션 로그 `(observation, action)` 쌍은 디버깅 도구인 동시에 곧 SFT 데이터셋이다.
- day one부터 학습 재사용 가능한 포맷으로 설계한다.
- 그렇게 하면 모든 대화형 세션이 데이터가 된다.

## 7. 확정된 진행 흐름

1. v0: 학습 없이 Stage 0 에이전트 + 델타 관찰 루프를 먼저 돌린다.
2. 세션 로그를 축적한다.
3. 로그가 충분해지면 Stage 1 SFT로 넘어간다.
